QuizRounds v3.9 — validação final

ROOT CAUSE
- Realtime: CLOSED de canal removido intencionalmente podia agendar reconexão concorrente.
- Ranking: innerHTML era refeito a cada polling/broadcast, reaplicando animação e causando piscada.

CORREÇÕES
- epoch/identity guard para canais Realtime em ADM/Jogador/Telão.
- timer de reconexão único + fallback de polling.
- guards de sequência para RPCs de estado fora de ordem.
- ranking por assinatura: sem DOM rewrite se posição/pontos não mudaram.
- mínimo 1 participante para iniciar; sem máximo artificial no fluxo de lobby.
- migration 010 aplicada ao Supabase.
- CSS compartilhado sem camada antiga do jogador; jogador usa CSS isolado.

TESTES ESTÁTICOS
- JavaScript: node --check aprovado em todos os assets ativos.

- GitHub Pages: workflow mantém bloqueio para sb_secret_ e exige sb_publishable_.

QuizRounds v3.50 — Gambás profissionais em padrão RPG Maker

Formato de cada personagem:
- PNG RGBA com transparência.
- Grade 3 colunas x 4 linhas.
- Linha 1: BAIXO / FRENTE.
- Linha 2: ESQUERDA.
- Linha 3: DIREITA.
- Linha 4: CIMA / COSTAS.
- Cada linha possui 3 frames para animação.

Avatares ativos:
- Cientista F / M
- Química(o) F / M
- Sala limpa F / M
- Petroleiro(a) Operação F / M
- Petroleiro(a) Manutenção F / M

Todos os personagens são os gambazinhos profissionais derivados das folhas de sprites fornecidas pelo usuário.
Os petroleiros usam macacão laranja no catálogo final.
